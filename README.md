## LangNest — Collaborative Language Learning Platform

LangNest is a collaborative platform designed for developers to explore, learn, and build using their favorite programming languages and tech stacks.

##  Links
- **Frontend Repo:** https://github.com/Sharuna-mk/Langnest-frontend
- **Backend Repo:** https://github.com/Sharuna-mk/Langnest-backend

## Tech Stack
**Frontend:** React.js, Tailwind CSS, React Router, React Icons, Context API, Axios, Flowbite  
**Backend:** Node.js, Express.js, MongoDB, Socket.IO, JWT, Bcrypt.js, Cloudinary, Stripe

## Features

### 👤 User
- Create, update, search, and delete posts (up to 3 images per post)
- Real-time messaging via Socket.IO
- Report other users' posts
- Full profile CRUD
- Toggle dark / light mode
- Subscription payments via Stripe — free users limited to 3 posts
 
### 🛡 Admin
- View and manage all users
- Remove posts by setting an limit
- View billing and subscription data
- Analytics dashboard with charts
- Pagination across all views
